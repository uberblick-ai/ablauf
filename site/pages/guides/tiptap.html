ablauf / Guides / Tiptap

Draw diagrams in a Tiptap editor.

In Markdown an ablauf diagram is a fenced code block with the language ablauf. Tiptap reads that as an ordinary code block, so one small extension is enough: it draws the diagram above its source while the source stays editable text, and the Markdown comes back out unchanged.

The Markdown

A document holds the diagram as text, so it diffs, reviews and merges like the rest of the file. An agent writes it the same way, after reading the format primer.

Install

This guide uses Tiptap 3 with its Markdown extension. render has no dependencies and no Node.js APIs, so it runs in the browser as it is.

npm install @uberblick/ablauf @tiptap/core @tiptap/pm @tiptap/starter-kit @tiptap/extension-code-block @tiptap/markdown

The extension

It extends Tiptap's code block with a node view: the picture sits above the <pre> that holds the source, and is shown only when the block's language is ablauf. Every other code block looks as before. The editor then swaps the starter kit's code block for this one.

import CodeBlock from "@tiptap/extension-code-block";
import { render } from "@uberblick/ablauf";

let diagrams = 0;

// A code block that draws itself when its language is ablauf. The source
// stays the editable content, so Markdown keeps the fence as it is.
export const AblaufCodeBlock = CodeBlock.extend({
  addNodeView() {
    return ({ node }) => {
      const dom = document.createElement("div");
      const picture = document.createElement("div");
      const pre = document.createElement("pre");
      const code = document.createElement("code");
      picture.className = "ablauf";
      picture.contentEditable = "false";
      pre.append(code);
      dom.append(picture, pre);

      // Ids inside one SVG must not clash with another diagram's.
      const idPrefix = `ablauf-${++diagrams}`;
      let drawn: string | null = null;
      const draw = (n: typeof node) => {
        const language = n.attrs.language;
        code.className = language ? `language-${language}` : "";
        picture.hidden = language !== "ablauf";
        if (picture.hidden || n.textContent === drawn) return;
        drawn = n.textContent;
        const { svg, diagnostics } = render(drawn, { idPrefix });
        picture.innerHTML = svg;
        picture.title = diagnostics.map((d) => `line ${d.line}: ${d.message}`).join("\n");
      };
      draw(node);

      return {
        dom,
        contentDOM: code,
        update(updated) {
          if (updated.type !== node.type) return false;
          draw(updated);
          return true;
        },
        // The picture is ours, not ProseMirror's to re-read.
        ignoreMutation: (m) => picture.contains(m.target),
      };
    };
  },
});
import { Editor } from "@tiptap/core";
import { Markdown } from "@tiptap/markdown";
import StarterKit from "@tiptap/starter-kit";
import { AblaufCodeBlock } from "./ablauf-block.ts";

export const editor = (element: HTMLElement, markdown: string) =>
  new Editor({
    element,
    extensions: [StarterKit.configure({ codeBlock: false }), AblaufCodeBlock, Markdown],
    content: markdown,
    contentType: "markdown",
  });
/* The picture above its source. The --ab-* properties give it your page's
   colours; see Customise colours for the full list. */
.ablauf {
  overflow-x: auto;
  padding: 12px 0;
  --ab-bg: #ffffff;
  --ab-ink: #1d1b24;
}
.ablauf svg {
  display: block;
  max-width: none;
  height: auto;
}

What it does

  • The source stays the block's content. Typing, undo, collaboration and the Markdown output work as for any code block, and editor.getMarkdown() writes the same fence back.
  • The picture is redrawn only when the text changes, so moving the cursor costs nothing. A diagram of a few dozen lines renders in well under a frame.
  • The renderer never throws. While someone types, it draws what it can, and the problems, each with its line number, go to the picture's title. A list under the picture works just as well.
  • Each diagram gets its own idPrefix, so the ids inside one inline SVG never clash with another's on the same page.

Outside an editor the pattern is the same: wherever your Markdown renderer handles fenced code, call render(source) for the ablauf language and put the SVG in its place. To match your page's colours, see customise colours.
