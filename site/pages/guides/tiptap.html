ablauf / Guides / Tiptap

Draw diagrams in a Tiptap editor.

In Markdown an ablauf diagram is a fenced code block with the language ablauf. Tiptap reads that as an ordinary code block, so one small extension is enough: it draws the diagram above its source while the source stays editable text, and the Markdown comes back out unchanged.

The Markdown

A document holds the diagram as text, so it diffs, reviews and merges like the rest of the file. An agent writes it the same way, after reading the format primer.

Install

This guide uses Tiptap 3 with its Markdown extension. render has no dependencies and no Node.js APIs, so it runs in the browser as it is.

npm install @uberblick/ablauf @tiptap/core @tiptap/pm @tiptap/starter-kit @tiptap/extension-code-block @tiptap/markdown

The extension

It extends Tiptap's code block with a node view: the picture sits above the <pre> that holds the source, and is shown only when the block's language is ablauf. Every other code block looks as before. The editor then swaps the starter kit's code block for this one. The files are in the repository under examples/tiptap:

  • ablauf-block.ts, the code block with its node view.
  • editor.ts, an editor with Markdown in and out.
  • ablauf.css, room and colours for the picture.

Copy them into your project; they are about 70 lines in all.

What it does

  • The source stays the block's content. Typing, undo, collaboration and the Markdown output work as for any code block, and editor.getMarkdown() writes the same fence back.
  • The picture is redrawn only when the text changes, so moving the cursor costs nothing. A diagram of a few dozen lines renders in well under a frame.
  • The renderer never throws. While someone types, it draws what it can, and the problems, each with its line number, go to the picture's title. A list under the picture works just as well.
  • Each diagram gets its own idPrefix, so the ids inside one inline SVG never clash with another's on the same page.

Outside an editor the pattern is the same: wherever your Markdown renderer handles fenced code, call render(source) for the ablauf language and put the SVG in its place. To match your page's colours, see customise colours.
