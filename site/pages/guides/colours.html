Customise colours

A diagram takes every colour from --ab-* custom properties, with light and dark defaults that follow the reader's system. Set the properties in your page's CSS and an inline diagram picks them up, with no new render.

The defaults

Rendered with no options and no host CSS, a diagram uses its built-in palette and follows prefers-color-scheme. This page sets only the neutrals to its own text, line and panel colours.

Match your page's neutrals

Text, outlines, node surfaces and section bands come from six properties. Set them on a wrapper, here .paper, or on :root for every diagram on the page. --ab-bg is the colour behind the diagram: the SVG itself is transparent, and edge crossings are cut out in that colour.

Brand the tones

Each tone has a foreground for text, outlines, edges and arrowheads, and a background for shapes. Override only the tones you use; the others keep their defaults.

Follow a theme switch

Both examples follow the system's light or dark mode with a media query. If your page has its own switch, such as data-theme="dark" on the root element, put the dark values under that selector instead. Set every property in both themes, so a page in light mode on a dark system stays consistent.

Page CSS reaches a diagram only when its <svg> is inline in the page. An SVG loaded through <img> is its own document; render it with scheme: "light" or "dark" to pin a palette instead.
