Text format and renderer · MIT license

Diagrams agents write and people read.

ablauf is a small text format for diagrams, rendered as deterministic, themed SVG. It is inspired by Mermaid, with a simpler layout that the author controls: you decide where each step sits and which side each edge leaves and enters. The source stays plain text that agents can read and write and that fits in a Markdown code block, and the picture aims to be easier for people to read.

More flows

A deploy pipeline. columns names the columns, each node starts a new row unless row= puts it beside another, and from= and to= pick the sides an edge leaves and enters.

The renderer never moves anything.

Why we built it

Automatic layout looks fine until someone edits the diagram, and then every node jumps. In ablauf the author places each node in a named column and a row, and picks the side each edge leaves and enters. Inserting a step moves what is below it down a row; every node keeps its column and its place in the order.

The renderer sizes the grid and draws. When a placement does not work, such as an edge crossing a node or two labels overlapping, it still draws the diagram and reports the problem with its line number. A diagram is done when it has no problems, which is something an agent can check without seeing the picture.

The output is one inert SVG with its own styles. It follows the reader's light or dark theme, or the host page's, through --ab-* custom properties, and the same source always gives the same bytes. See customise colours.

One format, several kinds.

The first line of a diagram names its kind. More kinds are planned on the same grid.

Render it in a build script.

render(source, options?) returns the SVG and a list of problems, each with its line number. It needs Node.js 22.18 or newer and has no runtime dependencies.

render-flow.mjs
import { readFile, writeFile } from "node:fs/promises";
import { render } from "@uberblick/ablauf";

const [input, output] = process.argv.slice(2);
const { svg, diagnostics } = render(await readFile(input, "utf8"));
await writeFile(output, svg);

for (const { line, severity, message } of diagnostics) {
  console.error(`${input}:${line} ${severity}: ${message}`);
}
process.exitCode = diagnostics.length ? 1 : 0;
